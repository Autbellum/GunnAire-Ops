# Embedded mechanical workspace in GunnAire Ops

The Ops Estimates workspace now links the local LoadSightUI Swift package and presents LoadSightFileWorkspaceView. The entry uses the existing financial-detail access check, estimate workspace mode and job-documentation exclusion. The exported package type identifies `.loadsight` folders for the system picker.

The host can create a mechanical project, import a package or self-contained JSON, use the shared takeoff/calculation/RFI/CO editors, and export a package or portable JSON. Import fully decodes before replacing the working copy. Changes are explicit exports; closing or starting another project with unsaved edits prompts Keep editing or Discard. Export captures a value snapshot and marks only that snapshot saved on successful completion. JSON retains drawing originals through the existing document serializer.

This integration does not bind customers/jobs, convert costs to selling prices, create Ops estimates or publish billing. Existing catalog pricing, authenticated approval and backend authority require a separately reviewed mapping workflow. The shared model remains a draft workspace.

Verification evidence is under `output/verification/ops-embedding/`. Before snapshots preserve the three existing Ops files exactly, including unrelated user changes. `integration-only.patch` isolates this integration. The local-copy manifest records SHA-256 hashes. The original iCloud project build waited in NSFileCoordinator while opening the project; `icloud-build-stack-sample.txt` records that stack. Only our waiting xcodebuild was stopped. The subsequent build uses an isolated source copy under `/tmp`, with the local package and Config directory, leaving iCloud settings untouched.

The shared package passes 139 model tests. Full Ops build and native smoke-test results are recorded below when complete. The UI smoke test uses a UUID-named local SwiftData store, disables CloudKit with existing DEBUG test flags, and uses existing synthetic screenshot fixtures. It opens from Estimates, creates a blank project and returns to Ops. File-picker/export-dialog and unsaved-edit interactions need additional runtime acceptance.

Final native test passed on the iOS 26.2 QA iPad: Estimates entry, blank project creation, Overview draft state and return to Ops. The first test reached Estimates but searched above a lower entry; the entry was moved to the top for discoverability. Import/export dialogs and unsaved-edit UI remain additional acceptance work.
